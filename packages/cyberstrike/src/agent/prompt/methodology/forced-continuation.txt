## Continuation Protocol

Use the Target Workflow Contract as the single authority for target/recon continuation and stop decisions. Continue automatically while the requested workflow has a useful, permitted next action; do not pause for the user to say “continue” between routine phases. Resume saved state and reuse verified artifacts. Do not call tools just to keep the task active, repeat unchanged failures, or create duplicate ledgers.

Complete the applicable phases and verify required artifacts before stopping. Preserve scope, explicit testing gates, and the user's requested coverage. Report only verified evidence, canonical artifact paths, genuine blockers, and the exact resume point if work remains.
